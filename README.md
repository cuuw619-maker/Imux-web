# Imux Web

Initial browser prototype of the Imux voxel game.

## Run
Serve the repository with any static HTTP server, then open `index.html`.
ES modules and Three.js are loaded from jsDelivr.

## Current base
- Three.js WebGL renderer
- First-person pointer lock
- WASD movement
- Gravity and jumping
- Procedural starter terrain
- Basic block registry
- Crosshair and hotbar foundation

Next layers: raycast block interaction, chunk meshing, texture atlas, sky/panorama, inventory, saving and optimization.
